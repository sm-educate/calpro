# 🧮 Multi-Purpose Calculation Hub (`calpro`)

A modern, responsive online calculation suite designed for students, educators, and professionals. Features interactive calculators for finance, health, standard math, and unit conversions.

🌐 **Live Demo:** [https://sm-educate.github.io/calpro/](https://sm-educate.github.io/calpro/)

## ✨ Featured Calculators
* **Finance & Investment:** Loan / Mortgage Amortization, Compound Interest & Investment Growth curves.
* **Fitness & Health:** Body Mass Index (BMI) Solver, Daily Calorie & TDEE (Total Daily Energy Expenditure) Estimator.
* **Math & Science:** Interactive Scientific / Standard Keypad with memory registers, percentage change & proportion solver.
* **Unit Converters:** Instant conversions across standard scientific and physical units.

## 🛠️ Built With
* HTML5
* CSS3 / Tailwind CSS
* JavaScript
